# NotreShare

A full-stack expense-sharing web application for managing shared expenses, groups, balances, and settlements.

NotreShare makes it easy for friends, roommates, teams, and travel groups to track shared spending and settle up without complicated calculations.

## Live Demo

🌐 **[NotreShare](https://notreshare.vercel.app)**

## Tech Stack

### Frontend
- React
- Vite
- React Router
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- JWT Authentication
- bcrypt

### Database
- Supabase
- PostgreSQL
- JSONB for flexible group membership and expense split data

### Deployment
- Vercel
- GitHub
